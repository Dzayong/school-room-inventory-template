TEMPLATE PROYEK INVENTARIS SEKOLAH

File yang harus diisi:
1. index.html            -> Beranda
2. rooms.html            -> Daftar ruangan
3. inventory.html        -> Tabel inventaris
4. report.html           -> Form laporan kerusakan
5. documentation.html   -> Foto dan dokumentasi
6. team.html             -> Profil anggota tim
7. images/               -> Masukkan foto aktual hasil observasi

ATURAN PENGERJAAN:
- Jangan hapus struktur HTML utama sebelum memahami fungsinya.
- Ganti semua teks <!-- TODO --> dengan data kelompok.
- Tambahkan baris <tr> jika data ruangan/inventaris lebih banyak.
- Gunakan foto hasil observasi sendiri.
- Pastikan nama file gambar sama persis dengan yang ditulis pada src="...".
- Gunakan HTML semantic seperti header, nav, main, section, article, dan footer.
- Form laporan hanya tampilan. Data belum tersimpan karena proyek ini belum memakai backend/database.
